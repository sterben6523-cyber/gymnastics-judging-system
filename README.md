# Система судейства по художественной гимнастике

Веб-приложение для автоматизации судейства соревнований.

## Стек
Python, Flask, SQLite, Bootstrap

## Функционал
- Регистрация администратора при первом запуске
- Импорт гимнастов из Excel
- Добавление гимнастов с выбором предметов
- Добавление судей с типом и номером (E, A, DB, DA)
- Автоматический подсчёт оценок
- Публичное табло результатов
- QR-авторизация судей

## Запуск
```bash
pip install -r requirements.txt
python app.py
