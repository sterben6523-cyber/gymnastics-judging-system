Дипломная работа на тему "Проектирование и программная реализация веб-ориентированной информационной 
системы для обработки и верификации судейских данных в художественной гимнастике", был спроектирован сайт для судейства выступлений по гимнастике, в проекте присутствуют 2 роли судья и администратор.
При первом запуске пользователь должен зарегистрировать основного администратора(Важно!! запомните логин и пароль так как второй раз окно не появится после нажатия создать), администратор регистрирует судей выдавая тип судьи и номер для каждого выступления котором судья будет присутствовать, также он вносит атлетов в систему и выступления, по окончанию выступления создаёт отчёт в котором можно соединить несколько выступлений(если по какой-то причине пришлось перенести выступление на другой день).
Судья оценивает выступления в специальных полях, судья видит только свой профиль с оцениванием и только те выступления в которые ему дали доступ.
